# DARA Carousel Maker Platform

**DARA Carousel Maker** is a web-based platform engineered for content creators, marketers, founders, and social media strategists to design, generate, and publish high-converting social carousels (LinkedIn, Instagram, Twitter/X).

## Features
- **Template-First Design System**: Instant visual layout styling with custom color tokens and typography.
- **AI Copywriting & Creative Director Engine**: Hook generation, story flow structuring, and slide copy creation.
- **Pixel-Perfect Canvas Editor**: Drag-and-drop layer manipulation (text, shapes, images, logos) at 1080x1440 4:5 vertical carousel format.
- **Multi-Provider AI Routing**: Integration for OpenAI, Anthropic, Gemini, Replicate, and Fal.ai.
- **Multi-Format Export**: PNG, ZIP bundle, and LinkedIn multi-page Carousel PDF exports.

## Tech Stack
- **Frontend**: Single-Page Application (SPA) built with Vanilla HTML5, ES2024 JavaScript, and CSS3 design system tokens.
- **Storage**: LocalStorage state persistence with debounced auto-saves.

## Quick Start
1. Open `index.html` directly in your browser, or
2. Run a local server:
   ```bash
   npm start
   ```
   Open `http://localhost:3000` (or the port reported by serve).
